Detailed Description

Cross-platform audio input coordinator for CsoundUnity.

Add this component to the same GameObject as CsoundUnity, together with both NativeAudioInputManager and WebGLAudioInput. In Awake the router enables the appropriate component for the current platform and disables the other, so the same scene works in the Unity Editor, on desktop / mobile, and in a WebGL build without any manual changes.

Recommended Inspector setup on the GameObject:

  1. CsoundUnity — assign the CSD as usual.
  2. NativeAudioInputManager — set channels / buffer as needed; leave Open On Initialized as desired (the router does not override it).
  3. WebGLAudioInput — set channels as needed; leave Open On Initialized as desired.
  4. CsoundUnityAudioInputRouter — just add it; no configuration required.

Platform routing:

  • Editor / Standalone / iOS / Android / visionOS: NativeAudioInputManager enabled, WebGLAudioInput disabled.
  • WebGL build: WebGLAudioInput enabled, NativeAudioInputManager disabled (its Open() is a no-op on WebGL anyway, but disabling it avoids the warning log).
