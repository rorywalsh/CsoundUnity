Detailed Description

A Csound instance on a thread of its own, started with -n -d so it touches no audio device. Used for work that must not run on the audio thread: rendering a csd to a file, and scanning a csd for the channels its orchestra allocates.

◆ Destroy()

override bool Csound.Unity.CsoundWorker.Destroy ( )
inlinevirtual

Joins the performance thread, then frees the instance.

The order is the point: csoundDestroy takes an internal Csound lock that csoundPerformKsmps holds, so freeing while the thread is still inside it deadlocks. Dispose does not return until the thread has exited.

Returns
Whatever the base teardown returns: true when the instance was freed.

void Csound.Unity.CsoundWorker.ScanCsdForChannels ( string csdString,
Action< IDictionary< string, CsoundUnityBridge.ChannelInfo > > onComplete )
inlinestatic

Scans a CSD string in a temporary, isolated Csound instance (−n −d, no audio I/O). After compiling the CSD and running one PerformKsmps, all channels allocated by the orchestra are queried and returned via onComplete .

The callback is invoked on the background scan thread. To update Unity or Editor state, marshal back to the main thread (e.g. via EditorApplication.update).

Parameters
csdStringFull CSD content as a string.
onCompleteInvoked with a dictionary mapping channel name → CsoundUnityBridge.ChannelInfo.
