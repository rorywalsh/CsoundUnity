Detailed Description

A set of control channel values for one csd, saved as an asset.

A preset carries values and nothing else: the channel definition — type, range, skew, increment, a combobox's option list — belongs to the csd. Create one with CsoundUnity.CreatePreset(string, string, List<CsoundChannelController>), and apply it with CsoundUnity.SetPreset(CsoundUnityPreset).
