Detailed Description

Shared static registry of CsoundChildEntry objects for the CsoundUnityChild IAudioGenerator path.

Mirrors the design of CsoundBridgeRegistry: each child stores only an integer ID in its unmanaged CsoundChildRealtime struct and looks up the managed entry at audio-thread time.
