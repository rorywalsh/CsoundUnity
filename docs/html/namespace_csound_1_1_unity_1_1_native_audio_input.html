enum Csound.Unity.NativeAudioInput.NativeInputState

State of the NativeAudioInputManager.

Enumerator
Stopped 

No input session is active.

Opening 

Opening the native device.

Running 

Native session running (CoreAudio / AAudio).

Fallback 

AAudio unavailable; using Unity Microphone API fallback.

Error 

Open failed on all paths.

NotSupported 

Platform does not support NativeAudioInputManager. On WebGL, use WebGLAudioInput instead.
