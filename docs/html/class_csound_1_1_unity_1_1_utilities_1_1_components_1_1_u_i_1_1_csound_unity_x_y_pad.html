Detailed Description

A Unity UI XY Pad that sends two Csound channel values in real time via drag gestures.

Widget mode: reads channel names and ranges automatically from a Cabbage xypad widget in the CSD. Assign the X channel name (first channel of the xypad widget) to _channel.

Manual mode: specify both channel names and all ranges directly in the inspector. Works with any two Csound channels — no xypad widget required in the CSD.
