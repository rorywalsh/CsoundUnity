Detailed Description

Control struct for CsoundUnityChild IAudioGenerator path.

Fully unmanaged struct implementing GeneratorInstance.IControl (with CsoundChildRealtime) and GeneratorInstance.ICapabilities. Its only job is to synchronise CsoundChildRealtime.InstanceId before each audio block.
