Detailed Description

Attach to each key button in a Canvas piano keyboard. Forwards pointer-down / pointer-up (mouse and touch) to CsoundUnityKeyboard as note-on / note-off events.

Setup per key:

  1. Add a UI Button (or any RectTransform with a Graphic) to the Canvas.
  2. Add this component to that GameObject.
  3. Assign the CsoundUnityKeyboard reference.
  4. Set _semitone (0 = C, 1 = C#, 2 = D … 11 = B).

The sounding MIDI note is resolved at runtime as keyboard.BaseOctave × 12 + semitone, so octave-shift on the keyboard automatically affects all keys.
