 The value in Csound's terms. Cabbage comboboxes are 1-based, 0 meaning "no selection", while value holds the 0-based index Unity's dropdowns use — so a combobox reads back one higher. The value in Csound's terms. Cabbage comboboxes are 1-based, 0 meaning "no selection", while value holds the 0-based index Unity's dropdowns use — so a combobox reads back one higher. ◆ IsContinuous

bool Csound.Unity.CsoundChannelController.IsContinuous
get

True when this channel holds a number to slide through rather than a state to switch, so interpolating it means something: the sliders and the two-value widgets.

A button, a checkbox or a combobox has no meaningful halfway point, which is why those are snapped instead — see DiscreteChannelMode.
