Detailed Description

Provides runtime access to CsoundUnityScorePlayableBehaviour instances running inside a PlayableDirector.

Attach to any GameObject in the scene. Assign a PlayableDirector. The controller traverses the PlayableGraph one frame after the director starts playing, caches all score behaviour instances, and exposes their API methods so UI scripts can control BPM, pattern steps, step notes, etc. at runtime.

If the timeline loops (graph is rebuilt by Unity), call Recollect or subscribe to OnBehavioursCollected to refresh UI state.
