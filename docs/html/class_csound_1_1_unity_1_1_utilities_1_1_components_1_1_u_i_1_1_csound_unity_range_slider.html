Detailed Description

A Unity UI Range Slider that drives two Csound channels (min and max) simultaneously using two independent draggable handles on a shared track.

Widget mode: reads channel names, range, and default values automatically from a Cabbage hrange or vrange widget in the CSD. Assign the min channel name (first channel in channel("minChan","maxChan")) to _channel.

Manual mode: specify both channel names, the absolute range, and default values directly in the inspector. Works with any two Csound channels — no CSD widget required.

Orientation: enable _vertical for a vertical track (bottom = min, top = max). The CsoundUnity_VRangeSlider prefab has this enabled by default.

Prefab setup: the RangeSlider GameObject needs a background track image. Add two child GameObjects as handles (assign to _handleMin / _handleMax) and optionally a fill child (assign to _fill) whose anchors are driven automatically between the two handle positions. Set both handle RectTransforms to anchorMin = anchorMax = (0.5, 0.5) and pivot = (0.5, 0.5); the component updates their anchorMin/Max each frame.
