Detailed Description

Vector synthesis component: blends four CsoundUnityPreset placed at the corners of a unit square using bilinear interpolation, driven by a 2D position in [0,1]×[0,1]. Inspired by the Sequential Prophet VS and Korg Wavestation vector synthesis paradigm.

Set position from any external script (XY pad, mouse, MIDI CC, etc.), or enable automate to let the component move the position automatically using one of the built-in AutomationMode patterns.
