Detailed Description

Maps physical keyboard keys to MIDI note events sent to CsoundUnity. Corresponds to the Cabbage keyboard widget.

Physical key layout (one octave, piano-style):

W E T Y U ← black keys (sharps)
A S D F G H J ← white keys C D E F G A B

Use OctaveDown / OctaveUp (or Z / X keys) to shift the octave. Call NoteOn / NoteOff from on-screen button events to drive a visual piano keyboard prefab.

Note events are dispatched via CsoundUnity.SendMidiNoteOn / CsoundUnity.SendMidiNoteOff, so the target CSD must use a MIDI-aware instrument (e.g. one with massign or global MIDI input opcodes).
