Detailed Description

Shared foundation for StepUIBuilder and PatternUIBuilder. Owns the clip-navigation chip strip, the BPM display, and all UI-helper primitives that are byte-for-byte identical in both concrete builders.

Subclasses implement the abstract interface to supply mode-specific behaviour: which clips to show, how long a natural cycle is, and how to wire/clear listeners.
