int Csound.Unity.Utilities.SceneObjectUtils.GetRuntimeId ( Object value)
inlinestatic

Returns an opaque integer key for an object within the current play session.

Parameters
valueThe object to identify, or null.
Returns
A stable nonzero key for the object, or zero for null.

Use this key for runtime lookups, not persistent asset identity. Unity 6.6 entity identifiers are kept intact in the lookup; older editors use their instance identifiers.
