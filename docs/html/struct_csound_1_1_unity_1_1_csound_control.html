Detailed Description

Layer 2a — Control state (control thread).

Fully unmanaged struct implementing GeneratorInstance.IControl (with CsoundRealtime) and GeneratorInstance.ICapabilities. Unity requires TControl to be unmanaged (same constraint as TRealtime), so this struct stores only an int InstanceId and resolves the bridge through CsoundBridgeRegistry, the same registry the realtime struct uses.

Unity calls Configure on the control thread when the generator is first used and again whenever the audio system reconfigures — not once per audio block. Unity's own documentation is explicit about this, and adds that during a reconfiguration the instance is suspended from processing, so its properties can be modified safely from there. Nothing reacts to a reconfiguration yet; see the audio-path documentation.
