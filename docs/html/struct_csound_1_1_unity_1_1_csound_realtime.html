Detailed Description

Layer 2b — Realtime state (audio thread).

Fully unmanaged struct implementing GeneratorInstance.IRealtime. Unity calls Process on every audio block to fill the output buffer.

The struct is stored in Unity's unmanaged audio memory (ptr->HeaderAndProcessor.UserProcessor), so _ksmpsIndex persists correctly across consecutive Process calls — exactly as CsoundUnity.ksmpsIndex persists across OnAudioFilterRead calls.

The Csound bridge is resolved through CsoundBridgeRegistry so that this struct can remain unmanaged (required by Unity's TRealtime constraint).
