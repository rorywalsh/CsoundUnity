enum Csound.Unity.Utilities.RemapUtils.SkewMode

Controls how the skew factor is interpreted when remapping values.

Enumerator
Cabbage 

Skew factor has no upper bound. Values below 1 produce exponential mapping, 1 produces linear mapping, and values above 1 produce logarithmic mapping.

Normalized 

Skew factor is normalised to the 0–1 range. Values below 0.5 produce exponential mapping, 0.5 produces linear mapping, and values above 0.5 produce logarithmic mapping.

Remaps a float value from one range to another with optional clamping and skewing. There are two possible modes for skewing: Cabbage and Normalized.

In Cabbage mode, the skew factor has no upper limit and the mapping behaves as follows:

  • Exponential mapping for values above 0 to 1
  • Linear mapping at 1
  • Logarithmic mapping for values above 1

In Normalized mode, the skew factor is bound between 0 and 1, and the mapping behaves as follows:

  • Exponential mapping from values above 0 to 0.5
  • Linear mapping at 0.5
  • Logarithmic mapping for values above 0.5 to 1

Both modes return the lower target bound (from2) when the skew is 0 or below. The Normalized mode returns the upper target bound (to2) when the skew is 1 or above.

Remaps a normalised 0–1 value to the given output range, with an optional power-curve skew. A skew of 1 gives a linear mapping; values below 1 compress the lower end (exponential feel).
