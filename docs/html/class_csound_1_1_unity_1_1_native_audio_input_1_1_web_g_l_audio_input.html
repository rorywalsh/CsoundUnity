Detailed Description

WebGL audio input: the browser microphone, as seen from C#.

An orchestra that reads input already has a microphone. When the CSD declares nchnls_i ≥ 1 and reads adc, Csound opens the device itself inside its own start() — and in the worker variations it refuses to do it any later — so Open reports the stream that is already running rather than opening a second one. That is what IsOpen answers for, and it is the only account of the browser input that C# has: on WebGL no handle exists to ask Csound for a channel count or a rate. A CSD that does not read input is the case where this component opens a stream itself, and where a deviceId or a channel count has any effect.

This component compiles on all platforms so it can coexist with NativeAudioInputManager in the same scene. Use CsoundUnityAudioInputRouter to automatically activate the correct component at runtime based on the current platform.

On non-WebGL platforms Open is a no-op (logs a warning). Audio routing is handled by the browser's Web Audio graph; NativeAudioInputManager is not used.

Multi-channel limitation: browsers cap getUserMedia at stereo (2 channels) regardless of the connected hardware. CSD opcodes reading nchnls_i > 2 will receive silence on extra channels.

The browser shows a microphone permission prompt on the first Open call. Serve your build over HTTPS — getUserMedia fails on plain HTTP.
