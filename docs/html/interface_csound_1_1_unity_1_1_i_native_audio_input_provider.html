Detailed Description

Implemented by Csound.Unity.NativeAudioInput.NativeAudioInputManager. When assigned to CsoundUnity.nativeAudioInputProvider, this method is called once per ksmps boundary (before PerformKsmps) on the Unity audio thread to write captured microphone samples into the Csound spin buffer.
