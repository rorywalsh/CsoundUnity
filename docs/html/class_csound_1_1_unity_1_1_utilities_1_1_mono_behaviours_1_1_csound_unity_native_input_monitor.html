Detailed Description

On-screen panel for NativeAudioInputManager: which device is open, whether anything is arriving, an input meter, and a list to switch device without leaving play mode.

Add it to diagnose an input that stays silent. The device is the one setting that decides between working and apparent silence, and nothing on screen moves either way — so the panel leads with a verdict and a meter, and keeps the ring counters behind a toggle, where they belong: that part is for debugging the plugin, not for choosing a microphone.

Drawn with IMGUI, so it needs no Canvas and no EventSystem, and it draws nothing at all while ShowPanel is off.
