Detailed Description

Shared static registry of Csound bridges for the IAudioGenerator path.

CsoundUnity registers its bridge here, on the AudioPath.IAudioGenerator and AudioPath.RootOutput paths, so that the fully unmanaged CsoundRealtime and CsoundRootRealtime structs can resolve it by integer index on the audio thread, without holding any managed references themselves.

Slots are never removed from the lists — they are nulled on unregister — so IDs stay stable for as long as the lists do. That is one Play session: ResetForNewPlaySession clears them at each start, because with domain reload disabled the statics outlive a session and would otherwise carry dead slots into the next one.
