inlinestatic

Writes an audio file from the provided AudioClip to the specified destination. The output format is determined by the file extension of destination ; WAV and AIFF are supported.

Parameters
clipThe AudioClip containing the audio data.
destinationThe destination path for the output audio file, including the file extension.
bitsPerSampleThe desired bits per sample of the output audio file (default: 16).
fallbackToWavWhen true, falls back to WAV format if the destination has no extension or an unsupported one. Default is false.
Returns
True if the writing succeeds; false otherwise.
