Enumerator

Route added successfully; no cycle in the audio graph.

AddedWithCycle 

Route added despite a circular dependency (forceConnection was true).

RejectedCycle 

Route rejected because it would create a circular dependency.

InvalidSource 

Route rejected because source was null.

AlreadyExists 

Route not added because an identical one (same source, channel, and spin channel) already exists.
