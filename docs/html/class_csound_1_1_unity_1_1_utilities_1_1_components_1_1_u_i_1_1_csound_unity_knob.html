Detailed Description

A rotary knob UI component that drives a single Csound channel, corresponding to a Cabbage rslider widget.

The knob image rotates between _minAngle (min value) and _maxAngle (max value). Interaction uses vertical drag: drag up to increase, drag down to decrease (standard DAW convention).

Prefab setup: assign the rotating Image to _knobImage. The image pivot should be at its centre. Optionally assign label and value Text references.
