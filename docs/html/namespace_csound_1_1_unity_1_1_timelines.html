◆ CsoundUnityScoreStateMatch

enum Csound.Unity.Timelines.CsoundUnityScoreStateMatch

How a saved state was matched back to a clip, for the log and the tests.

Enumerator
None 

No state in the snapshot belongs to this clip.

AssetId 

Matched by clip asset instance id, which is what survives a graph rebuild.

ClipId 

Matched by the clip's durable id.

Name 

Matched by clip name, which is only tried when one of the two sides has no id.

Index 

Matched by position, only when neither side has ids and the counts agree.

◆ CsoundUnityTimelineClipEndReason

enum Csound.Unity.Timelines.CsoundUnityTimelineClipEndReason

Why an active clip left playback. Pauses and graph rebuilds do not end a clip.

Enumerator
None 

No end: the event is the clip starting.

Completed 

The clip reached its end.

Stopped 

The director stopped.

Seek 

The playhead was moved out of the clip.

Loop 

The director wrapped around to the start.

ControllerDisabled 

The controller was disabled.

Removed 

The clip is no longer in the graph.
