◆ BuildPitchArray()

float[] Csound.Unity.Utilities.MusicUtils.BuildPitchArray ( float rootHz,
Scale scale,
int octaves,
bool includeClosingRoot = false )
inlinestatic

Builds a flat array of frequencies in Hz spanning octaves octaves of the given scale, starting from rootHz .

When includeClosingRoot is true, each octave ends with the root of the next octave as a turnaround note — use this for ArpDirection.UpDown so the top note is included (e.g. A B C D E F G A G F E D C B A). When false (default), no closing root is added — use this for ArpDirection.Up / ArpDirection.Down / ArpDirection.Random so the cycle repeats without duplicating the root (e.g. A B C D E F G | A B C D E F G | ...).

Parameters
rootHzThe frequency the scale starts from.
scaleThe scale to walk.
octavesHow many octaves to stack.
includeClosingRootWhen true each octave ends with its own root.
Returns
The frequencies in Hz, low to high.

◆ BuildPitchArrayFromChord()

float[] Csound.Unity.Utilities.MusicUtils.BuildPitchArrayFromChord ( float rootHz,
Chord chord,
int octaves,
int[] customIntervals = null,
bool includeClosingRoot = false )
inlinestatic

Builds a flat array of frequencies in Hz from a chord, spanning octaves octaves. Chord intervals may already span more than one octave (e.g. 9ths, 11ths, 13ths); additional octaves stack the same intervals shifted up by 12 semitones per octave.

For Chord.Custom, pass the custom semitone intervals via customIntervals . If null or empty, falls back to Chord.Major.

includeClosingRoot adds the root of the next octave after each octave block — use this for ArpDirection.UpDown turnaround (same semantics as BuildPitchArray).

Parameters
rootHzThe frequency the chord is built on.
chordThe chord to stack.
octavesHow many octaves to stack.
customIntervalsThe semitone intervals used when chord is Chord.Custom.
includeClosingRootWhen true each octave ends with its own root.
Returns
The frequencies in Hz, low to high.
