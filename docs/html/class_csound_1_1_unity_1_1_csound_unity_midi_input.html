Detailed Description

Platform-agnostic MIDI input component for CsoundUnity. Add this component to the same GameObject as CsoundUnity (or assign the CsoundUnity reference in the inspector). Make sure the CSD has <CsOptions> -M0 </CsOptions> to activate Csound's MIDI subsystem.

Platform support: macOS / iOS / visionOS — CoreMIDI (USB, BLE, Network MIDI); Android — android.media.midi (USB + BLE, API 23+); Windows — WinMM (short MIDI messages; SysEx not supported); WebGL — Web MIDI API (Chrome/Edge, HTTPS).

On Android and WebGL the backend delivers messages with UnitySendMessage, which addresses a GameObject by name: with two of them named the same, every message goes to the first one Unity finds and the other receives nothing. Give each GameObject carrying this component a distinct name. CoreMIDI and WinMM address the receiver directly.

In addition to forwarding messages to Csound, this component fires C# events (NoteOn, NoteOff, ControlChange, ProgramChange) that any other script can subscribe to for non-Csound purposes.
