◆ AudioDisplayMode

enum Csound.Unity.Utilities.MonoBehaviours.AudioDisplayMode

Defines the audio source used by AudioDisplay to retrieve signal data. Modes ending in "Spectrum" perform FFT and display the frequency spectrum. All other modes display the raw waveform.

Enumerator
AudioListener 

Reads spectrum data from the scene's AudioListener using Unity's native FFT. Shows the frequency spectrum of the entire scene's mixed audio output. No additional setup required.

AudioSource 

Reads spectrum data from an AudioSource using Unity's native FFT. Works correctly only when the AudioSource is playing a real AudioClip.

Limitation: does NOT reflect audio injected via OnAudioFilterRead — GetSpectrumData reads the clip's source signal, not the post-filter output. Use RawSamplesSpectrum if audio is injected via OnAudioFilterRead.

Assign the AudioSource in the inspector, or leave empty to use the one on this GameObject.

CsoundUnityOutput 

Reads raw samples from the CsoundUnity.OutputBuffer property and displays them as a waveform (no FFT). The buffer size equals ksmps.

Requires updateOutputBuffer to be enabled on the CsoundUnity component.

Assign the CsoundUnity instance in the inspector.

CsoundUnityAudioChannel 

Reads raw samples from a named CsoundUnity audio channel (written in Csound with chnseta) and displays them as a waveform (no FFT). Buffer size equals ksmps.

Assign the CsoundUnity instance and the channel name in the inspector.

RawSamples 

Displays samples provided externally via AudioDisplay.SetSamples as a waveform (no FFT). Call SetSamples every frame with fresh data.

RawSamplesSpectrum 

Computes the frequency spectrum via FFT on samples provided externally via AudioDisplay.SetSamples, then displays the result.

This is the correct mode when audio is injected via OnAudioFilterRead: split L/R channels in OnAudioFilterRead, call SetSamples each frame, and the display will show the per-instrument spectrum efficiently.

Input length must be a power of 2. FFT update rate is configurable via AudioDisplay._fftUpdateRate to trade refresh rate for performance.

◆ SpectrumWeighting

enum Csound.Unity.Utilities.MonoBehaviours.SpectrumWeighting

Per-bin weighting curve applied in spectrum modes only.

Enumerator
Flat 

No per-bin weighting — the FFT magnitude is used as-is.

Quadratic 

Multiply each bin by (1 + i²) — emphasises high-frequency bins to compensate for their naturally lower energy in FFT spectra.
