Detailed Description

A Unity UI Slider component that integrates with CsoundUnity. Automatically maps the slider range (0-1) to the min/max of a named Csound channel, and updates the channel value in real time as the slider is moved. Exposes Value, ChannelValue and Active properties to control the slider and the associated Csound instrument programmatically.
