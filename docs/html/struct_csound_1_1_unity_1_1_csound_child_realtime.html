Detailed Description

Realtime struct for CsoundUnityChild IAudioGenerator path.

Fully unmanaged struct implementing GeneratorInstance.IRealtime. Reads audio from the snapshots the parent CsoundUnity publishes at the end of each block, reached through CsoundChildRegistry.

No call to PerformKsmps is made here — Csound processing is entirely owned by the parent's CsoundRealtime. This struct is purely a data reader.

Called by Unity on every audio block (audio thread). Pulls one complete published block per channel from the parent and writes it into buffer .

Nothing here reads the parent's live working arrays: the two audio callbacks are not ordered against each other, so doing so meant sometimes seeing a block that was only half written. Taking published snapshots costs at most one DSP buffer of latency — constant, rather than varying with whichever callback happened to run first — and a parent that has stopped publishing yields silence instead of a looped last block.
