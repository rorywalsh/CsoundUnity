Detailed Description

Utility class for real-time FFT spectrum analysis.

Implements an iterative Cooley-Tukey radix-2 DIT (Decimation-In-Time) FFT. Compared to a naive recursive implementation or one based on System.Numerics.Complex, this version has zero per-call heap allocations: all working buffers (_re, _im, _window, _spectrum) are static and allocated once the first time a given input size is seen.

Thread safety: the static buffers are shared across all callers on the same thread. CalculateSpectrum is safe to call from the main thread only. If multiple AudioDisplay instances need independent results, each must copy the returned array immediately (as AudioDisplay already does internally).

float[] Csound.Unity.Utilities.FFTUtils.CalculateSpectrum ( float[] input)
inlinestatic

Computes the magnitude spectrum of a real-valued audio signal via FFT.

Processing steps:

  1. Apply a Hann window to reduce spectral leakage at buffer boundaries.
  2. Bit-reversal permutation to prepare for in-place butterfly computation.
  3. Iterative Cooley-Tukey butterfly stages (O(n log n)).
  4. Compute magnitude for the first N/2 bins and scale to single-sided amplitude (2/N scale factor so a full-scale sinusoid reads ≈ its amplitude).

Input constraints: input must be non-null, non-empty, and a power-of-2 length. Returns Array.Empty<T> on invalid input.

Return value: a reference to the internal static _spectrum buffer (length = input.Length / 2). The caller must copy the result before the next call if it needs to retain it — see AudioDisplay for an example.

Parameters
inputReal-valued audio samples. Length must be a power of 2.
Returns
Magnitude spectrum, length input.Length / 2. Do not store the reference.
