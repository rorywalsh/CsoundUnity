Detailed Description

Records what Unity finally plays, every channel of it, into a WAV file.

It belongs on the GameObject that carries the AudioListener: its OnAudioFilterRead there receives the mix of the whole scene, at the width of the speaker mode and after panning, so what lands in the file is what left for the hardware. Not only Csound: anything else the scene plays is in it too.

Two things it cannot see. AudioPath.RootOutput writes past the listener, so a CsoundUnity on that path does not appear here; record that from the device instead. And the AudioListener's own volume is applied after this point.
