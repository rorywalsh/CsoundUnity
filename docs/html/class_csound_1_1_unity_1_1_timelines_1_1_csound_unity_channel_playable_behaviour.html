Detailed Description

The PlayableBehaviour for a single clip on a CsoundUnityChannelTrack. Holds the target value for the Csound channel that will be blended by CsoundUnityMixerBehaviour. Supports three modes: Fixed (constant value), Random (S&H stepped), RandomSmooth (interpolated).

◆ ChannelMode

enum Csound.Unity.Timelines.CsoundUnityChannelPlayableBehaviour.ChannelMode

How the clip produces its value: a constant, a stepped random value, or a random value glided between steps.

Enumerator
Fixed 

One constant value for the whole clip.

Random 

A new random value at every step, held until the next one.

RandomSmooth 

A new random value at every step, glided to from the previous one.
