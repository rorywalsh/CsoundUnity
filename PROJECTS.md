# Projects that use CsoundUnity

We put together this initial list by searching GitHub and the web for public projects that use CsoundUnity. We'd love to see what you've built with it.

Add a row to this table in a pull request, or [open an issue](https://github.com/rorywalsh/CsoundUnity/issues/new) with the project name, who to credit, one sentence about how you used CsoundUnity, and a public link to its source, a demo, a download, or a project page. Include any related papers. See [Papers on CsoundUnity](PAPERS.md) for projects documented only in a publication. Include a year if you can point to a release, exhibition, demo, or publication.

Entries run from the most recent documented year to the earliest, alphabetically within each year. **≤2023** means the project was publicly documented by 2023.
